# Tarea 3 - MongoDB

Conexión de API con MongoDB y pruebas CRUD con Postman.

---

## 🛠️ Instalación y Ejecución

Sigue estos pasos para clonar el repositorio e iniciar la aplicación localmente:

### 1. Clonar el repositorio

```bash
git clone [https://github.com/andreaguinder/tarea-3-mongodb.git](https://github.com/andreaguinder/tarea-3-mongodb.git)
cd clase-3-Node
```
### 2. Instalar las dependencias

```bash
    npm install
```
### 3. Configurar las variables de entorno

Creá un archivo llamado **`.env`** en la raíz del proyecto (al mismo nivel que el `package.json`) y agregá las siguientes variables con tus datos de conexión:

```bash
PORT=3000
MONGODB_URL=tu_cadena_de_conexion_a_mongodb
```

> *Nota: Si usás MongoDB local, podés usar `mongodb://localhost:27017/nombre_de_tu_base`. Si usás MongoDB Atlas, pegá tu URI completa de la nube.*

### 4. Ejecutar la aplicación

```bash
    npm run dev
```
